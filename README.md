
# Mazameras Collab

This is a Next.js collaborative writing platform built in Firebase Studio.

## How to Deploy

The project is ready to be deployed on platforms like Vercel or Netlify.

### Required Environment Variables

To connect to the Firebase Firestore database, you need to set the following environment variables in your hosting provider's dashboard (e.g., Vercel):

- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID`
- `NEXT_PUBLIC_FIREBASE_APP_ID`

You can get these values from your Firebase project settings.
